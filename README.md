# JB3D — Site

Esta é a versão inicial do site estático de demonstração para o repositório jb3dprint.github.io.

Arquivos adicionados:
- index.html
- assets/css/style.css
- assets/js/main.js
- assets/images/* (imagens de exemplo - coloque suas imagens reais aqui)

Como usar:
1. Suba imagens reais para assets/images (por exemplo, hero.jpg, model1.jpg ... model5.jpg).
2. Publique com GitHub Pages (branch `main`, raiz do projeto).

Se quiser eu posso adicionar imagens de espaço reservado (SVG) ou integrar um gerador de páginas como Jekyll ou eleventy.
